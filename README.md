# Pairs-Trading-Implementation
Tried implementing the Long-short pairs trading strategy across 2 universe: ETF and Equity.

This is a work in progress. Have tried testing the strategy on 1-min and 5-min bars, but adding the transaction costs cuts the profits, so optimization over selection of granularity of price updates is what needs to be done after which the Scaling and regime detection will be optimized.

Data files in .parquet format, too big for repo upload.
